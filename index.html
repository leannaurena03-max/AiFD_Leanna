Behind the work

Poster Generator — My Process

My poster generator started with the bold lettering, strong contrast, and upside-down text in the WITNESS NYC poster. Since the first version, it has developed into a working tool where I can change the text, fonts, colors, and layouts to create different posters. One of the hardest parts was getting a complete working file because the first version’s code was cut off. I also had to check that the exported posters were actually editable in Illustrator, and I was able to change the words and move the shapes. There is still room to improve the spacing and make sure different amounts of text work well. This process showed me that AI can help turn a design idea into custom software, but I still need to give clear instructions, test the results, and make decisions about what looks right.
