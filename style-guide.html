My visual direction · 01

A style guide for my AI

CleanSportyStructured

These are the design rules for my class homepage. I want it to feel simple, organized, and easy to use, with a little movement and a pop of green. Follow these decisions every time you build or edit my page.

01

The Page

Leanna Urena
FULL-WIDTH HERO IMAGE

Structure & inspiration

Build a one-page index of my assignments. Put my name at the top left, with a wide hero image underneath and the assignment links below it.

Use Apple as a reference for simplicity, Nike for strong imagery, and Adidas for a sporty, structured feel.

Keep the hero image at full content width and its natural aspect ratio, with a 3px corner radius. Use the index image, nyc-hero.png, with descriptive alt text and a small caption over the lower left corner.

02

The Palette

Background#F3F2EB
Text#242925
Accent#204B3B

Warm paper, dark ink & forest green

Use warm off-white paper (#F3F2EB) for the background, dark ink (#242925) for primary text, and forest green (#204B3B) for emphasis and the footer.

Assignment tabs use pale sage (#E5E9DD), forest-green text, and soft borders (#C9D0C5). On hover or keyboard focus, use a forest-green fill with paper-colored text.

Use muted green-gray (#586359) for supporting text. Keep these six colors consistent with the index.

Arial + Helvetica / Monospace labels

Simple & readable

Use Arial with Helvetica and sans-serif fallbacks. The main heading is bold at weight 700, with clamp(45px, 7.6vw, 108px), a .92 line height, and -.075em letter spacing. Set its second line in forest green.

Use 12px uppercase navigation with .12em tracking, 14px uppercase section headings, and 15px body text with a 1.6–1.7 line height. On phones, navigation is 10px and intro body text is 13px.

Use bold 24px monospace assignment numbers and 18px titles at weight 600. Use 10–11px monospace for course details and supporting labels; allow longer titles to wrap.

The Details

Interaction & movement

Make desktop assignment tabs 82px wide and 112px tall, with 20px vertical and 24px horizontal padding. Expand to the full column width on hover or keyboard focus, revealing the title and arrow.

Animate tab width over .55s with cubic-bezier(.22, 1, .36, 1); fade in the title and arrow after .12s. Use a 3px forest-green focus outline with a 6px offset. On phones and touch devices, show full-width tabs and titles immediately.

Use a subtle 1.3s entrance on the hero image and a slow 28s turn on the decorative asterisk beside the assignments. Respect reduced-motion preferences by disabling animations and transitions.

The build rules

  1. Center the index content with a width of min(1320px, 90%). Use the same width for the header, main content, and footer contents.
  2. Use two assignment columns on desktop and one at 760px and below. Place a short note beside the desktop assignment grid; hide it on mobile.
  3. Use 14px row gaps and 24px column gaps between assignments. Give the desktop intro 48px top and 54px bottom padding; use 30px and 36px on mobile.
  4. Use a forest-green footer with paper-colored text. Keep decorative motion limited to the hero entrance and the desktop asterisk.
  5. Use one main heading, descriptive image alt text, real assignment links, and clearly visible keyboard focus.
  6. Keep these decisions consistent whenever new assignments are added. This guide uses two columns to compare examples; the homepage assignment grid follows rule 2.
